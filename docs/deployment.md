# Vinx Vocab 运行、部署与验证

面向使用者的安装说明（Windows 双击、NAS、导入旧数据、配置项）在 [README](../README.md)；本文是开发和验收时用的补充。

## 一、本地运行

```bash
make build                                   # 构建前端并嵌入，生成 dist/vinx-vocab
./dist/vinx-vocab seed-demo --data /tmp/vinx-demo   # 演示数据（可重跑）
./dist/vinx-vocab --data /tmp/vinx-demo --port 3200  # 监听 0.0.0.0:3200
```

- 演示账号：`admin` / `teacher` / `student` / `student2@vinx.test`，密码 `dev123456`；演示班级邀请码 `DEMO01`。
- 全新数据目录（不跑 `seed-demo`）用来验证首次运行向导：打开后先选版本，再注册第一个账号（自动成为管理员）。
- 前端开发：`pnpm -C web dev`，Vite 把 `/api` 代理到 `API_TARGET`（指向运行中的 Go 实例，如 `http://localhost:3200`）。
- 手机访问用电脑的局域网地址；同一设备固定一个地址（cookie 按主机名归属）。

## 二、三条主线怎么走（浏览器验证时照着走）

### 1. 老师带班

1. **班级 → 新建班级**，把 6 位邀请码发给学生；或在「成员」页 **批量创建学生账号**（输入姓名列表 + 账号前缀 + 初始密码，生成 `前缀01、前缀02…`）。
2. 班级页 **学习计划 → 为本班新建计划**：选词书单元 → 每天新词数（默认 10）/复习上限（默认 50）→ 题型（认义、拼写）→ 创建。
3. 每天打开 **班级 → 今日概览**：谁完成了、谁没开始、连续天数、近 7 天正确率、班级难词榜；点学生名看其完整记录。

### 2. 学生学习

1. 注册时填邀请码（或登录后在「个人中心」输入），「今日」自动出现班级计划。
2. 点 **学新词**：认识卡片（可朗读）→ 认义选择 → 拼写 → 答错的词再练到对 → 结果。每组最多 10 个新词，可连续学多组直到当天额度。
3. 第二天起 **复习** 出现到期词；**错词强化** 随时加练，不影响复习安排。
4. 「我的单词」看每个词的记忆状态与复习轨迹，「学习记录」看趋势与每一组的逐题详情。

### 3. 自主学习

「学习计划 → 新建计划」或从词书详情「用所选单元建计划」，对象默认本人；也可建「一次检测」计划给自己测验。

## 三、关键规则速查

| 规则 | 说明 |
|---|---|
| 今日额度 | 新词 = 每天新词数 − 今天已学（缺席不累计）；复习 = min(到期词, 复习上限 − 今天已复习) |
| 自动评分 | 新学：全对=模糊（次日复习），有错=忘记；复习：全对=记得，部分对或用提示=模糊，全错=忘记；检测只更新已学词；错词强化不更新 |
| 证据口径 | 只看练习/检测的**首次作答**；巩固阶段重做不计入正确率和评分 |
| 掌握分层 | FSRS 稳定性 <7 天学习中，7–21 天巩固中，≥21 天已掌握 |
| 中断续做 | 同一计划同一类型只有一个进行中的组；刷新或换设备打开会从断点继续；中途「结束本组」只结算练完的词 |
| 记忆去重 | 同一个词一天最多更新一次记忆；多个计划范围重叠时，到期词只在最早的每日计划里复习 |
| 检测成绩 | 首次交卷为正式成绩，可重测练习但不再影响复习安排 |
| 账号代管 | 老师只能为自己批量创建的账号重置密码；自行注册的学生凭邀请码入班 |
| 学习日 | `APP_TIMEZONE` 自然日，默认 Asia/Shanghai |

## 四、词书与导入

- 内置词书：七年级上册～九年级上册（按 Unit）、中考核心词汇（按首字母分单元），来自 `data/vocab/`，全新数据目录首次启动时自动导入。
- 「词书 → 导入词表」：粘贴或上传 txt → 解析预览（标出缺音标、疑似粘连等问题，可逐条修改）→ 导入到已有或新建词书。拼写全局去重，已有词条直接复用。

## 五、两个版本（个人版 / 班级版）

没设 `VINX_EDITION` 时首次运行选择，管理员可在「系统设置 → 版本」双向切换（K43）；设了则以它为准。

| | 个人版 | 班级版 |
|---|---|---|
| 班级、成员、批量建号 | ✗ | ✓ |
| 给班级/学生安排计划 | ✗（只能给自己安排） | ✓ |
| 用户管理与角色 | ✗（只允许一个账号；降级前已有的账号仍能登录） | ✓ |
| 学习、词书、AI、发音、记录 | ✓ | ✓ |

班级版专属后端逻辑在 `internal/school/`，路由用 `r.Feature(...)` 按请求判定，关闭时返回 404。

## 六、AI 与发音（可选）

- AI：管理员在「系统设置」页填写 OpenAI 兼容接口或 Claude，测试后保存，立即生效；也可用 `AI_*` 环境变量。未配置时相关入口隐藏。E2E 自带假 AI 服务，不需要真实接口。
- 发音：按 `AUDIO_PROVIDER_URL` 抓取并缓存到数据目录 `audio/`，失败回退浏览器合成语音。全量预缓存：`vinx-vocab audio prefetch --data <目录>`（默认演练，`--apply` 实际抓取，限速 1.5 秒）。
- 出站请求走 `HTTPS_PROXY` / `HTTP_PROXY`。systemd 服务不继承登录 shell 的代理变量，需要时写进单元的 `Environment=`。

## 七、部署

- 构建：`make cross` 生成 `dist/vinx-vocab.exe` 与 `dist/vinx-vocab`，版本号取 `git describe`。
- Linux：见 README 的 systemd 示例；一定要指定 `--data`。升级 = 停服务、替换文件、启动（有迁移时自动备份数据库）。
- 从服务器版迁移：见 README「从服务器版导入」。先停本程序；旧版不用停。
- 部署、重启服务、改系统配置属于先说明再执行的操作。

## 八、部署后检查

- `curl http://<地址>/api/health` 返回成功，响应头带 `X-Vinx-Vocab`。
- **用真实浏览器打开并走一遍登录**（桌面 + 手机视口）。命令行调接口查不出 Origin 与 cookie 配错导致的登录失败。
- 验收用的临时账号测完删除。
