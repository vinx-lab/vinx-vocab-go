# Vinx Vocab 功能与使用流程

本文面向**推广、演示和新用户**：用使用者的话讲清楚这个系统能做什么、每类人怎么用、每个流程一步步怎么走。规则的精确定义见 [product.md](product.md)，每条规则的来由见 [decisions.md](decisions.md)，安装与运行见 [README](../README.md)。

> 写推广材料时请以本文为准，不要扩大说法：这里没写的功能就是没有（见第 11 节「不做什么」）。

---

## 1. 一句话介绍

**Vinx Vocab 是一个面向初中生的英语背单词系统：学生每天打开只看到「今天要做什么」，点一下就开始；老师只需要建班、选单元、定每天几个词；什么时候复习由记忆算法自动安排。**

它打包成**一个可执行文件**：Windows 上双击就能用，不用装数据库、不用注册云账号；同一个 Wi-Fi 下的手机用浏览器就能背单词。放到一台 Linux 小主机或 NAS 上，就是一个班级服务器。

## 2. 适合谁

| 用户 | 典型场景 | 用哪种形态 |
|---|---|---|
| 家长 / 自学的学生 | 家里一台电脑，孩子用手机或平板每天背 | 个人版（「自己用」） |
| 家里有几个孩子、或家长带几个孩子 | 每个孩子一个账号，家长看各自进度 | 班级版（「老师带班」） |
| 英语老师、辅导机构 | 一个或几个班，统一布置、统一看进度、打印单词单 | 班级版，放在一台常开的电脑或小服务器上 |

两种形态是同一个程序，首次打开时选择，之后管理员可以在「系统设置」里随时切换；从班级版切回个人版**不删任何数据**，切回来原样恢复。

## 3. 卖点（可直接用于宣传的事实）

1. **下载即用，数据在自己手里**：一个文件、双击运行，数据存在程序旁边的文件夹里，不上传到任何云端。复制这个文件夹就是完整备份。
2. **每天只看「今天要做什么」**：没有「欠了 N 天任务」的压力——缺几天不会堆出一大堆，新词额度不累计，该复习的词还在，按每天的复习上限慢慢消化。
3. **科学排程，不用自己打分**：复习时间由 FSRS 记忆算法计算（Anki 新版默认使用的算法）；学生不用自己判断「记得 / 模糊」，系统按答题结果自动评分。
4. **三种题型，从认识到会写**：看英文选中文、看中文拼写、例句挖空填词；每个词每种题型都要过一遍。
5. **「不会」就点「不会」**：不用盲猜，点「不会」算答错、马上看答案、会被安排更早复习，老师在明细里能区分「真不会」和「选错了」。
6. **每次作答都算数**：不管是每日学习、复习、错词强化、检测还是单词单，第一次作答都会更新这个词的记忆；第一次见就答对的词直接记为会了，不用再从头教一遍。
7. **纸笔和手机打通**：单词单、默写单按 A4 打印，在学校利用零碎时间看，回家在手机上测；默写单手写后在网页上点出错题，结果同样计入记忆和进度。
8. **老师一眼看全班**：每个学生今天学了没、复习完没、连续几天、正确率、目标词书覆盖了多少，一张表看完；还有全班难词榜。
9. **手机优先**：学习和测试在手机上完整可用——底部导航、大按钮、输入框不放大页面、深色模式。
10. **内置教材词表**：七年级上册到九年级上册五本教材词表，加中考核心词汇（按首字母分单元），首次启动自动导入；老师也可以导入自己的词表。
11. **真人发音**：单词发音来自在线真人录音并缓存在本地，之后不联网也能播；拿不到时自动换成浏览器朗读。
12. **AI 可选**：配置任意 OpenAI 兼容接口（含本地部署的大模型）或 Claude 后，可以补例句、生成重点句型和仿写、给学生生成用自己错词写的巩固短文。不配置 AI 时这些入口自动隐藏，其他功能不受影响。

## 4. 核心概念（用户只需要懂这四个）

| 概念 | 用户理解 |
|---|---|
| **词书 / 单元** | 教材、词表。单元里有「词表 / 句型 / 课文」三部分 |
| **学习计划** | 学哪些单元、每天几个新词、每天最多复习多少、练哪些题型 |
| **今日** | 按计划实时算出来的「今天要做的」 |
| **记录** | 每一组学习、每一道题、每个词现在记得怎么样 |

另外两个辅助概念：

- **目标词书**：这学期 / 这一年要覆盖的词书（如「八年级上册 + 中考核心词汇」），用来算「覆盖进度」。先定目标，再从目标里选单元建计划。
- **单词单 / 默写单**：可以打印的一份词（或句子），纸上看、手机上测，或纸上写、网页上批改。

## 5. 安装与第一次使用

### Windows（家庭、单台电脑）

1. 把 `vinx-vocab.exe` 放进一个自己建的文件夹（如 `D:\VinxVocab\`）。不要在压缩包里直接运行，也不要放进 `C:\Program Files\`。
2. 双击运行。第一次可能看到：
   - 「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」（程序没有代码签名）；
   - 防火墙提示：勾选「专用网络」并允许，否则手机连不上。
3. 黑色窗口里显示本机地址、局域网地址和数据目录，同时自动打开浏览器。**这个窗口就是服务，关掉窗口即停止。**
4. 第一次打开选择用法：**「自己用（个人版）」**或**「老师带班（班级版）」**。
5. **马上注册第一个账号**：全新安装时第一个注册的账号就是管理员。
6. 手机连同一个 Wi-Fi，在浏览器里打开窗口里显示的局域网地址（如 `http://192.168.1.10:3000`）。同一台设备请固定用同一个地址访问。

再次双击时如果程序已经在运行，只会打开浏览器，不会起第二个。

### Linux / NAS（班级服务器）

`./vinx-vocab --data <数据目录> --port 3000`，可配成开机自启的系统服务；放在反向代理后面也可以。详见 [README](../README.md)。

### 想先看看效果

运行 `vinx-vocab seed-demo` 会写入演示账号（管理员、老师、两个学生，密码 `dev123456`）、演示班级（邀请码 `DEMO01`）和演示计划，可以直接登录体验各角色。演示数据只用于体验，不要用在正式使用的数据目录里。

## 6. 学生：每天怎么用

### 6.1 今日页 —— 每天的唯一入口

打开就是「今日」，从上到下：

1. **连续天数、今日进度**。
2. **目标进度**（设了目标词书时）：已测 / 应测，以及各状态的词数；有「测未测的词」「练要学的词」两个快捷入口，直接生成一份单词单。
3. **每个计划一张卡片**：
   - 「学新词（还剩 N）」—— 今天还能学几个新词；
   - 「复习（到期 M）」—— 今天到期该复习的词；
   - 「检测」—— 老师或自己建的检测计划。
4. **单词单**：只显示下一份要测的，如「单词单 #2 · 30 词（还有 3 份待测）」。
5. **错词强化**：把最近常错的词拉出来再练一遍。

中途退出不会丢进度，再点同一个按钮就接着做。

### 6.2 学一组新词（每组最多 10 个）

全屏沉浸式，三步：

1. **认识**：一张张单词卡片——拼写、音标、词性、中文、例句，可以点发音，可以前后翻。
2. **练习**：每个词 × 每种题型各一题，打乱顺序。
   - 认义选择：看英文选中文（4 选 1，干扰项尽量同词性）；
   - 拼写：看中文和词性写英文，可以「提示首字母」（用了提示记为「模糊」）；
   - 挖空填词：例句里把这个词挖掉，填回去（没有例句的词自动跳过这一题型）。
   - 答错或点「不会」，马上显示正确答案。
3. **巩固错词**：练习里错过的词再做，直到答对（最多 3 轮）。

做完自动结算：系统根据**练习阶段第一次作答**给每个词评分，安排下次复习时间。新词当天只算「初步记住」，**第二天一定会再出现**。

学到一半想停，可以「结束本组」：练完的词照常计入，没练完的新词放回去，下次再学。

### 6.3 复习（每组最多 20 个）

练习 → 巩固错词 → 完成。全对的词复习间隔拉长；部分对或用了提示的，间隔小幅增加；全错的很快会再出现。

### 6.4 检测

连续作答、**中途不告诉对错**，交卷后出成绩单（逐题对错）。检测里的作答同样更新记忆；第一次见就答对的词直接记为「刚记住」，不用再从新词卡片学起；答错的生词留在新词池里，之后照常学。

### 6.5 错词强化

取最近 14 天答错或遗忘次数最多的词，练习 + 巩固。和复习一样更新记忆（每个词每天最多算一次）。

### 6.6 我的单词与记录

- **我的单词**：每个词现在的状态，可筛选「到期 / 困难 / 已掌握」，可搜索；点进去看这个词的完整复习轨迹（每次什么时候、在哪答的、对错）。
- **记录**：近 30 天学习量、正确率、记忆分布、连续天数；每一组学习的逐题明细。设了目标词书时，每本书一条进度条，点开按状态看词表。

**五级词状态**（覆盖进度、学习记录、老师的班级概览都用这一套）：

| 状态 | 含义 |
|---|---|
| 未接触 | 还没学过、也没测过 |
| 没记住 | 最近一次答错了 |
| 刚记住 | 答对了，但记忆还不牢（预计保持不到 7 天） |
| 巩固中 | 记忆预计保持 7–21 天 |
| 已掌握 | 记忆预计保持 21 天以上 |

另有两个提示标记：到期该复习的标「待复查」，估计已经快忘（回忆概率低于 70%）的标「可能忘了」。**到期不会自动降档**——不会出现「什么都没做，已掌握的词变少了」，要等下一次作答才变化。

### 6.7 计划与词书

- **计划**：分「老师给我的」和「我自己建的」。自己建计划只能从目标词书里选单元；没有设目标时不限制，但会提示先设目标。
- **词书**：按单元浏览「词表 / 句型 / 课文」，句子可以点读；单词详情里能看到它出现在哪些句子里；在单元页可以「用这个单元建计划」。

### 6.8 我的（个人中心）

资料、改密码、外观（跟随系统 / 浅色 / 深色，跟着账号走，换设备也一样）、凭邀请码加入班级、我的班级、目标词书。

## 7. 纸笔闭环：单词单与默写单

很多学生在学校不能用手机，但有零碎时间。单词单把「纸上看」和「手机上测」连起来。

### 7.1 单词单流程

1. **选来源**（「单词单」→ 新建）：
   - **不熟的词**（默认）：系统按最近答错、遗忘次数、记忆不牢、快到期等打分挑出来，已经掌握且一直没错的词不进来；
   - **某次测试的错词**：选近 30 天的某一次学习或测试，用那次答错的词；
   - **某个单元 / 整本书**：先放不熟的，再放没学过的。
   - 任何来源都可以再勾掉个别词，或搜索加词。
2. **定份数**：1–7 份 × 每份 10–30 词。词按从难到易分到各份，第 1 份最难，编号连续。
3. **打印**：每份一页 A4，中间一条折线，对折后外面两面是英文、里面是中文；双面打印时 4 份只用 2 张纸。打印页已去掉浏览器页眉页脚，不用改打印设置。
4. **带去学校看**，一天一份。
5. **回家在今日页测这一份**：和检测一样中途不反馈，交卷出成绩单。第一次交卷是正式成绩；同一张单子再测只算练习。
6. 成绩单上可以「用错词再出一张」。

同一个学生同一时间只会有一张单子在测；测单词单不影响当天的复习。

### 7.2 默写单（单词单的另一种格式）

1. 出单时选「默写单」：看中文写英文，可以混合单词、短语、句子、仿写、句式转换题。
2. 打印为**题目页 + 答案页**（可选横线或四线三格）。
3. 学生在纸上手写。
4. 在网页的**批改页**，默认全对，只点出错的题，提交一次。结果同样计入记忆和覆盖进度。
5. 学生自己的账号也能批改（适合家里没有老师的情况），会标记为「自批」；老师在班级概览里能看到每个学生的自批比例，必要时复核。

老师也可以在学生详情页替某个学生生成、打印单词单（测试仍由学生本人在自己账号里做）。

## 8. 目标词书与覆盖进度

计划会删、会过期，但「这学期要覆盖哪些词」是稳定的。覆盖进度跟着**目标词书**走，不跟着计划走。

- **谁来定**：老师给全班定（多个班取并集）；没有班级的人自己定；班级允许自主安排时，学生可以在班级目标之外再加自己的。
- **怎么算**：目标词书里的词按词去重，全部算进分母，没有「免测词」；每个词按五级状态统计。任何入口的作答都会推动进度——每日学习、复习、检测、单词单、默写单都算。
- **在哪看**：学生今日页顶部、记录页；老师的班级概览、学生详情。
- **先定目标再建计划**：建计划时只能从目标词书里选单元，保证学的东西一定计入目标进度。以前建的、超出目标的计划照常能学，会标「不在目标词书内」。

## 9. 老师：怎么带班（班级版）

老师拥有学生的全部功能（自己也能背单词），另外：

### 9.1 第一次开班（约 10 分钟）

1. **建班**：起班名，并选择是否「允许学生自主安排」：
   - 允许：学生可以在班级目标之外加自己的目标词书、自己建计划；班级概览按每个学生自己的目标统计。
   - 不允许：全班统一口径，学生不能自建计划（已有的自建计划自动暂停，重新允许时自动恢复）。
   - 之后在班级「设置」里可以改，关闭前会提示影响哪些学生和计划。
2. **拉学生进班**，三种方式任选：
   - 发**邀请码**，学生注册时填上，或注册后在「我的」里输入；
   - 按邮箱添加已有账号；
   - **批量创建学生账号**（老师可以替自己批量建的账号重置密码）。
3. **设目标词书**：在班级「目标词书」标签里选，如「八年级上册 + 中考核心词汇」。
4. **建计划**：选班级（或个别学生）→ 从目标词书里选单元 → 每天几个新词、每天最多复习几个、题型（认义 / 拼写 / 挖空）、按顺序还是随机、起止日期。也可以建一次性的检测计划。
   - 计划指向班级时，**之后才加入的学生自动获得这个计划**，不用补布置。

### 9.2 每天看一眼

**班级概览**一张表，每个学生一行：今日新学 / 复习完成情况、连续天数、最近学习时间、7 天正确率、已学词数、目标覆盖、待学词数、自批比例。下面是**班级难词榜**和本班计划。

点进某个学生，看到的和学生自己的「记录」一样（只读）：统计、每组明细、每个词的复习轨迹；还可以替他出单词单。

计划详情页显示每个学生在这个计划上的进度。

### 9.3 管词书

- 新建自己的词书，**导入 txt 词表**：先预览解析结果，改正后再确认；词表里可以带「句型」「课文」段。
- 编辑单元的句型和课文（粘贴导入、逐句编辑），调整单元顺序，设置词书学段（小学 / 初中 / 中考）。
- 编辑词条（同一个拼写全库只有一条，改一次所有词书都生效，编辑时会提示被几本词书引用）。
- **预缓存发音**：一键把整个单元的发音下载到本地。
- 配置 AI 后：给缺例句的词补例句、生成重点句型、照例句生成仿写变式（见第 10 节）。

## 10. AI 功能（可选）

管理员在「系统设置 → AI 接口」填写接口地址、模型和 Key，点测试，保存后立即生效。支持任意 OpenAI 兼容接口（含本地部署的模型）和 Claude；Key 加密保存，页面只显示末 4 位。不配置时所有 AI 入口隐藏。

| 功能 | 谁用 | 流程 |
|---|---|---|
| **AI 补例句** | 老师 | 选整个单元（每次最多 20 个缺例句的词）或单个词 → 预览这次用哪些词和发给 AI 的提示词，可以去掉个别词、可以改提示词 → 后台生成，生成即保存。有了例句，这些词就能出挖空填词题 |
| **重点句型、仿写变式** | 老师 | 按词书学段调整难度 → 先出草稿，系统自动检查（是否用到目标词、是否超纲、长度、仿写结构），只提示不拦截 → 老师审核后保存。课文不生成，只导入，保证与教材一致 |
| **巩固短文** | 学生 | 「短文巩固」页选词来源（到期 / 易错 / 最近学过 / 手选，3–15 个词）→ 预览单词和提示词，可调整 → 后台生成短文 + 中文翻译 + 理解题，目标词高亮、可点读。短文只用于阅读巩固，不影响记忆排程 |

生成都在后台进行，页面显示「生成中… 已用 N 秒」，失败时给出具体原因。管理员可以在「系统设置 → AI 提示词」里修改各类生成的默认要求，随时一键恢复默认。

## 11. 管理员

- **用户管理**（班级版，侧栏「用户」）：建账号、改角色（学生 / 老师 / 管理员）、重置密码。老师也能打开这个页面，但对账号的操作受限，例如只能给自己批量创建的学生重置密码，自己注册的学生只能凭邀请码自愿入班。
- **系统设置**：版本形态切换（个人版 ↔ 班级版）、AI 接口、AI 提示词。
- 维护系统内置词书。

个人版里唯一的账号就是管理员，同样能用系统设置。

## 12. 不做什么（推广时不要承诺）

- 排行榜、积分、社交、打卡分享。
- 课程解锁（学完第 1 单元才开第 2 单元）、一个计划里组合多种活动。
- 按个人数据训练记忆算法参数。
- 原生 App（手机用浏览器访问，界面已适配手机）；没有离线 App 模式，手机需要和服务在同一网络。
- 手机上打印、导出 PDF / Word、老师一键给全班每人生成单词单、纸面带例句、一份超过 30 词的单词单。
- 跨班搜索学生。
- 学生自评「记得 / 模糊」——一律由系统按作答判定。

## 13. 常见问题

**缺了几天没学，会不会堆一大堆？**
不会。新词额度不累计；到期的复习词会保留，但每天受复习上限约束，慢慢消化。

**为什么新学的词答对了，第二天还要复习？**
刚看过卡片就答对，不代表真记住了，所以新词当天只算初步记住，第二天一定再出现一次。

**同一个词在两本词书、两个计划里，会不会重复背？**
不会。每个学生每个词只有一份记忆，多个计划共享；一个词一天最多更新一次记忆。

**手机和电脑的登录状态不一样？**
登录按访问地址保存。同一台设备请固定用同一个地址（例如一直用 `http://192.168.1.10:3000`）。

**数据怎么备份、怎么搬家？**
停掉程序，复制整个数据目录（里面的 `vinx.db` 和 `secret.key` 要一起）。换电脑时把文件夹拷过去，用新的程序打开即可。

**升级会不会丢数据？**
替换程序文件即可；数据库结构有变化时，启动前会自动备份旧数据库。

**用过之前的服务器版（Node + PostgreSQL）？**
可以用 `import --from-postgres` 一次性导入全部数据，账号密码不变。见 [README](../README.md)。

**不联网能用吗？**
能。学习、测试、记录都在本地完成；已缓存的发音离线可播。只有首次获取发音和 AI 生成需要联网（或局域网里的本地大模型）。

## 14. 演示脚本（约 10 分钟）

适合给老师或家长现场演示，使用 `seed-demo` 演示数据：

1. **老师视角**（`teacher@vinx.test`）：班级列表 → 演示班级 → 班级概览表、难词榜 → 「目标词书」标签 → 本班计划。
2. **学生视角**（手机打开局域网地址，`student@vinx.test`）：今日页 → 学一组新词（认识 → 练习，故意答错一个、点一次「不会」→ 巩固）→ 回到今日看进度变化。
3. **单词单**：新建 → 来源「不熟的词」→ 2 份 × 20 词 → 打印预览（对折线、正反面）→ 回到今日页测一份 → 成绩单「用错词再出一张」。
4. **回到老师视角**：班级概览里刚才那个学生的今日新学、正确率已经变化 → 点进学生详情看逐题明细。
5. （配置了 AI 时）学生「短文巩固」生成一篇用自己错词写的短文。
