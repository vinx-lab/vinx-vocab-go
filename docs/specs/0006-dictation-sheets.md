# 默写单：看中文写英文，手写后由家长或老师批改录入

依赖 [0004](0004-sentences-passages.md)（句子）和 [0003](0003-target-books-coverage.md)（覆盖进度）。句型、仿写题的来源见 [0005](0005-ai-generation.md)。

## 问题

- 现在的单词单（K29、K35）是对折自测表：左栏英文、右栏中文，对折盖住一侧自测，**没有书写空间，也没有答案页**，不适合手写默写。
- 小学和初中的老师、家长常用「汉译英」默写单：给出中文，学生写出单词、短语、句子。现在只能在系统外手工排版，默写结果也不进系统，覆盖进度里看不到。
- 学生（尤其是小学生）要手写，不适合线上打字测试。

## 方案

### 1. 默写单是单词单的一种格式

- `WordSheet` 增加两列：
  - `format`：`selftest`（现有的对折自测表，默认）或 `dictation`（默写单）；
  - `items`：默写单的题目，JSON 数组，按顺序排列（见第 2 节）。
- 默写单和单词单**共用编号序列和列表**（K34 的连续取号不变），列表里用标签区分「自测」「默写」。
- 删除规则不变：只能删除从来没有批改过的默写单（对应 K29「只能删从未开过测试的单子」）。

### 2. 题型

| 类型 `type` | 卷面显示 | 学生写 | 答案 |
|---|---|---|---|
| `word` 单词 | 词性 + 中文，如「n. 句子」 | 单词 | 拼写 |
| `phrase` 短语 | 中文，如「大声朗读」 | 短语 | 短语 |
| `sentence` 句子 | 中文句子 | 整句英文 | 英文句子 |
| `frame` 仿写 | 例句 + 骨架 + 中文提示，如「I find ___ useful.（我发现做笔记很有用）」 | 整句 | 完整句 |
| `transform` 转换 | 原句 + 要求，如「改成一般疑问句」 | 转换后的句子 | 变式句 |

- `word` 和 `phrase` 来自词条（`Word.type` 区分）；`sentence` 来自句子；`frame` 来自带骨架的句子；`transform` 来自 `source = variant`、改动方式为「转换」的句子，原句取 `originId` 对应的句子。
- 一份默写单的结构：`items: [{ type, wordId? , sentenceId? }]`，卷面上按类型分成几个部分，依次是「一、单词」「二、短语」「三、句子」「四、仿写与转换」，只显示有题目的部分。

### 3. 出题

在单词单生成页（`/sheets/new`）顶部选择格式「自测表 / 默写单」。选「默写单」后：

- **词的来源**：沿用 K33 的来源（不熟的词 / 某次测试的错词 / 某个单元或整本书），加上 0003 新增的「目标：未测的词」「目标：要学的词」。可以分别勾选是否包含单词、短语。
- **句子的来源**：
  - 某个单元的篇：重点句型、课文、句型仿写，可以多选；
  - 「要学的句子」：最近一次正式测试写错的句子（第 6 节）；
  - 学生自己的 AI 短文：选一篇，从中挑句子。
- **数量**：每份的单词、短语、句子题数各自设上限，默认单词 20、短语 10、句子 8。份数 1～7 不变（K34）。句子按难度分到各份：要学的句子优先，其次是没测过的。
- **预览**：和现在一样，可以勾掉某些题，或者搜索添加。
- 老师在学生详情的「单词单」标签里同样可以为学生出默写单。

### 4. 打印版式

- 每份默写单 = **题目页** + **答案页**。答案页另起一页，页眉写「答案（家长 / 老师批改用）」，打印时可以选择是否打印答案页。
- 题目页：
  - 页眉：「VinxVocab 默写单 #N」、学生姓名、日期，以及「得分 ____ / 题数」。
  - 题号连续编排，每题左侧显示中文提示，右侧是书写区。
  - **书写区长度按答案长度分档**：单词一档、短语一档、句子占整行，句子太长时自动占两行。
  - **书写线可选「横线」或「四线三格」**：小学学段（0005 的 `primary`）默认用四线三格，其他学段默认横线。四线三格时行距加大。
- 答案页：按题号紧凑排成两栏，只写题号和答案。
- 和现有打印页一样：页边距为 0、不印页眉页脚（K35）、始终白底黑字。默写单不需要对折，没有折线。
- 合并打印：沿用 `/sheets/print?ids=…`，多份连续打印。

### 5. 批改录入

- 默写单的状态：待批改 → 已批改。今日页的单词单入口里，默写单显示「默写单 #N · 待批改」，不显示「测试」。
- **批改页** `/sheets/:id/grade`：
  - 逐题显示中文提示和标准答案，**默认全部算对**，点一下标为「错」（再点一下改回来）；
  - 可选：在错题旁记下学生实际写的内容（`userAnswer`），方便以后查看；
  - 页面底部显示「对 x / 错 y」，确认后提交。
- **谁能批改**：能查看这个学生记录的老师，以及学生本人的账号（家长通常用孩子的账号）。
  - 学生账号提交的批改标记为**「自批」**，成绩照常计入、照常推动记忆排程。
  - 老师在学生记录、默写单列表和成绩单里能看到「自批」标记；班级概览的「目标覆盖」旁显示其中自批的比例，必要时由老师复核（复核方式是再出一份默写单，由老师批改）。
  - 批改人和是否自批记在结果里（学习组快照的 `gradedBy`、`selfGraded`）。
- **只能提交一次**：提交后不能修改，与 K20「首次交卷为正式成绩」一致。提交前有确认弹窗。批改错了，可以在下一次默写或检测里纠正。
- 默写单**不能在线测试**，只能纸面默写后批改。其中的词照样可以通过其他自测单词单在线测。

### 6. 批改结果怎么记录

- 提交时新建一个已完成的学习组 `StudySession`（`kind = sheet`，`sheetId` 指向默写单，`completedAt` 为提交时间），快照里记下 `format = dictation` 和批改人。
- **词（单词、短语）**：每题写一条 `Answer`。`mode = dictation`（新增取值），`phase = test`，`attempt = 1`。`correct` 取批改结果，`userAnswer` 取记下的内容（可空）。
  - 按 K10 更新记忆：已经学过的词，对 → Good、错 → Again；没学过的词只记成绩。K19（每个词每个学习日最多更新一次记忆）照常适用。
  - 0003 的覆盖进度把它算作正式测试作答，所以对错会直接改变「会了 / 要学」。
- **句子题**（`sentence`、`frame`、`transform`）：写入新表

  ```sql
  CREATE TABLE "SentenceAnswer" (
    "id"         TEXT NOT NULL PRIMARY KEY,
    "sessionId"  TEXT NOT NULL REFERENCES "StudySession"("id") ON DELETE CASCADE,
    "userId"     TEXT NOT NULL REFERENCES "User"("id") ON DELETE CASCADE,
    "sentenceId" TEXT NOT NULL REFERENCES "Sentence"("id") ON DELETE CASCADE,
    "itemType"   TEXT NOT NULL,      -- sentence | frame | transform
    "correct"    INTEGER NOT NULL,
    "userAnswer" TEXT,
    "dayKey"     TEXT NOT NULL,
    "createdAt"  TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
  );
  CREATE INDEX "SentenceAnswer_user_sentence_idx" ON "SentenceAnswer"("userId", "sentenceId", "createdAt");
  ```

  句子不进 FSRS。每个句子的状态：没有作答为「未测」，最近一次错为「要学」，最近一次对为「会了」。

### 7. 结果显示

- **成绩单**：批改提交后显示和检测相同的成绩单（对错列表），加一个按钮「用错题再出一份」（K29「用错词再出一张」的扩展），错的词和句子一起进入新默写单。
- **记录页**：学习历史里出现「默写单 #N」，详情页逐题显示对错。
- **覆盖进度（0003 补充）**：目标词书的每个单元有句型、课文时，进度区块增加一行「句子：已测 x / y，会了 · 要学」，口径同上。等 0004 和本 spec 完成后，在 0003 里补写这一节。

### 8. 接口

| 接口 | 说明 |
|---|---|
| `POST /sheets/preview` | 现有接口，增加 `format`、`sentenceSources`、各题型数量 |
| `POST /sheets` | 现有接口，增加 `format`、`items` |
| `GET /sheets/:id` | 现有接口，默写单返回 `format`、`items`（含中文提示、答案、句子原句）以及批改状态 |
| `GET /sheets/sources` | 现有接口，增加单元的篇（句型、课文、仿写）和「要学的句子」数量 |
| `POST /sheets/:id/grade` `{ results: [{ index, correct, userAnswer? }] }` | 提交批改。必须包含全部题目；已批改的返回 409「这份默写单已经批改过」 |

### 9. 权限

- 出题、打印：沿用现有单词单的规则（学生本人、能查看这个学生的老师）。
- 批改：能查看这个学生的老师；学生本人的账号也可以，结果标记为「自批」（第 5 节）。
- 学生的 AI 短文作为句子来源时，只能用这个学生自己的短文。

## 取舍

- **作为单词单的一种格式，而不是新建「默写单」实体**：编号、列表、份数、打印、今日页入口都能复用，学生和老师只需要记住一个「单词单」入口。
- **人工批改，不做手写识别**：拍照识别手写英文准确率不稳定，校对成本比直接点「错」还高。默认全对、只点错题，批改一份 30 题的单子只需要几十秒。
- **不能在线测试**：默写练的就是手写，在线打字是另一回事。需要在线测的词有自测单词单。
- **学生账号可以自批，但要标记**：家庭使用（尤其是个人版、没有老师）必须能批改；自批有自己给自己打高分的风险，所以不隐藏、可追溯，由老师按需复核。考虑过只允许老师批改（个人版无人可批）和家长口令（多一步操作，还要另设口令），都没选。
- **批改只能提交一次**：与检测的正式成绩口径一致，防止反复修改成绩；改错的成本由下一次测试承担。
- **句子不进 FSRS**：先只记录对错，用「要学的句子」重新出题来巩固；句子复习排程以后再设计。

## 验证

- Go 单测：学生账号提交时 `selfGraded = true`、老师提交时为 false；题目切分（各题型数量上限、按份数分配、要学优先）；批改结果写入 `Answer` 和 `SentenceAnswer`，记忆按 K10 / K19 更新；重复提交返回 409；句子状态推算。
- 契约测试：新增用例只对单文件版运行。出默写单、详情、批改的权限（别人的学生 403）、批改后成绩单、错题再出一份。
- E2E：出一份包含单词、短语、句子的默写单 → 打印页显示题目页和答案页 → 批改页标两道错题并提交 → 今日页状态变成已批改 → 覆盖进度里对应的词变成「要学」。
- 打印检查：用 Chromium 打印成 PDF，检查 A4 一页的版式、四线三格、答案页另起一页、不印页眉页脚；再用真实打印机打一份确认书写区够宽。
- 手机 390×844：批改页的点击区域不小于 48px，可以单手逐题点。

### 与方案的差异

- 四线三格由生成页按所选词书的学段在打印链接上带参数决定，打印页可以手动切换。
- 老师替学生出默写单时没有「AI 短文」来源（短文只返回本人的）；句子只能勾选，不能搜索添加。
- 自批比例口径：已测目标词中，最近一次正式测试来自自批默写单的比例；今日页新增「今天已批改的默写单」。
- 打印分页改为「后一页之前分页」，自测表也受影响：不打印答案页时末尾不再多一张空白页。
- 真实浏览器检查发现：手机上批改页的提交栏被底部导航挡住（单词单生成栏同样，首次提交就有），已修复并加 E2E 用例（8b0481e）。
