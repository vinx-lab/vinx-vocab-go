## 命名

`NNNN-简短标题.md`，编号四位、递增，例如 `0001-test-wrong-drill.md`。

## 模板

```markdown
---
issue: 12          # 没有对应 issue 时删掉这一行
status: draft      # draft（写方案中）→ ready（等实现）→ done（已实现），或 dropped（不做）
---

# 标题

## 问题
要解决什么，谁会遇到，现在怎么绕过去。

## 方案
打算怎么做，影响哪些模块、接口和数据。

## 取舍
考虑过但没选的做法，以及原因。

## 验证
怎么证明做对了：单元测试、API 流程测试、E2E、真实手机检查。

## 结果
完成后补：实际改了什么、验证结果、未验证项、后续事项。
```
